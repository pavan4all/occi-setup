# Dorm Signage Instructions

### General Rules

- USE ONLY BLUE PAINTER’S TAPE (found in front of signage file box).
- Only tape course signs to bed frames, doors, or mirrors — NOT to walls.
- Never use masking, Scotch, or any other type of tape (per agreement with CYO regular management).

### Outside the Dorms

Cabin Assignment Numbers

1. - Use push pins (provided in the top of the file box).
   - Place the label outside each cabin in the triangle already there.

### Inside the Dorms

Bed Assignment Numbers

- “T” = top bunk, “B” = bottom bunk.
- Walk in the main entry to any dorm: the bunk to your left = Bunk #1. Go around the room (six bunks per dorm): 1T, 1B, 2T, 2B, 3T, 3B, 4T, 4B, 5T, 5B, 6T, 6B until all are labeled

Daily Timetables (4am–10pm)

- Total: 2

- One on each door

Group Sitting Timetable (morning, afternoon, evening)

- Total: 2
- One on each door

Bathing and Laundry Timetable

- Total: 1
- On mirror

Adjust Heat Sign

- Place below each thermostat

Room or Bed Change Sign

- Total: 1
- On each door

Maintain Noble Silence

- Total: 2
- On each door

Please Refrain from Physical Contact

- Total: 2
- One on the inside of each door
