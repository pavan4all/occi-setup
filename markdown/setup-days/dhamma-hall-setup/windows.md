# Window Covering

- When should this be done:   Day -2.  This is one of the first tasks we can start doing as this doesn't interfere with anything else
- How many people needed:  4 approx at a time on a window
- Tools and materials needed:  Ladder, pushpins, painters tape, white paper rolls
- Estimated time: 4-5 hours if done sequentially

### Important:

- Do not staple, or drive nails into the wood. Use ropes to tie cloth ends to existing fixtures.
- Only use Blue / Green Painter’s tape as other tapes leave marks on surfaces.  On some of the heavy canvases, you can use pushpins on the top section, but as little as possible. The idea is to not drill any new holes in the wood frame.
- Start papering the important areas first (e.g. Dhamma Hall) so that if we run out of paper, we are not in a difficult situation. If we run out of paper, we can also use extra blue “toppers” that are used on foam mats to cover windows.

Canvas update:

- As of 2024, the Canvas has marker writing (labels) on which canvas belongs where.  Please check that before starting to apply canvas, as that will save a LOT of time and avoid swaps later.  This might be hand written towards the bottom corner of the canvas in a permanent marker (likely orange color).
